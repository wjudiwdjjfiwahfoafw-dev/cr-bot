# Sprite library report

Generated by `tools/sanitize_sprite_library.py` over `assets/unit_sprites`.

Each frame is classified from its own colours: `score = log((blue_px+1)/(red_px+1))`
over hue-restricted team colours, so orange skin/wood/gold cannot vote.
Positive is the ally (blue) render, negative the enemy (red) render, |score| < 0.7 is `neutral`.

- card folders: **53**
- folders holding **both** tints (usable for either team): **28**
- folders holding **only one** tint (half the game's units cannot be matched): **24**
- folders with **no** measurable team colour: **1**
- cards in the card database with **no** sprite folder: **42**
